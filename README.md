# Wand Playground

杖を組み替えて試射する、ブラウザ向けのサンドボックスです。非公式のファン制作であり、原作とは挙動が異なります。原作の画像・音声・ソースコードは使用していません。

## 開発

Node.js 22 以降を用意し、以下を実行してください。

```sh
npm ci
npm run dev
```

`npm test` で単体テスト、`npm run build` で型チェックと本番ビルドを行います。
